# CNShadow

**用中文写 TypeScript / JavaScript / Python，磁盘里始终是纯英文源码。**

CNShadow 在编辑器和真实文件之间加了一层「影子视图」：你看到的是 `如果 / 函数 / 常量 / 控制台.输出`，
按下保存时自动还原成 `if / function / const / console.log` 写进磁盘。团队里其他人拉到的代码，和平时没有任何区别。

---

## 它是什么

- **中文写，英文存**：中文只存在于编辑器视图，磁盘、Git、CI、同事的电脑上永远是标准英文源码。
- **不是翻译，是双向映射**：中文视图里可以正常增删改代码，保存时逐 token 还原，格式与缩进不变。
- **内置 2790 条映射**：JS/TS 核心语法、DOM、Node、React/Vue/jQuery/Lodash 等常用库，Python 标准库与 NumPy/Pandas/Torch 等热门库。
- **中文模式不会满屏报错**：中文视图使用独立语言模式，内置语言服务不会介入；CNShadow 自己提供语法检查，真实错误照样能定位。
- **库成员补全**：输入 `.` 时列出中文成员名和英文原名，Python 还会实时读取模块的签名与文档首行。
- **中文视图直接运行**：标题栏点 ▶ 或按 `Ctrl+Alt+R`，插件自动把中文还原成英文后执行，不用切回英文。

## 快速开始

1. 安装插件（VSIX 或扩展市场搜索 **CNShadow**）。
2. 打开任意 `.ts` / `.js` / `.py` 文件。
3. 点编辑器标题栏的「中」图标，或按 `Ctrl+Alt+L`（macOS `Cmd+Alt+L`）。

```ts
// 中文视图里你看到并编辑的内容
类 用户服务 {
  校验(令牌) {
    如果 (令牌) {
      返回 真;
    } 否则如果 (令牌 === '') {
      返回 假;
    }
  }
}
```

```ts
// 保存后磁盘上的内容
class UserService {
  validate(token) {
    if (token) {
      return true;
    } else if (token === '') {
      return false;
    }
  }
}
```

## 在中文视图里直接运行

不用切回英文。在中文文档里按 `Ctrl+Alt+R`，或点标题栏的 ▶：

1. 插件先把中文内容反向还原成英文，写回真实文件（等同于保存）；
2. 再用对应运行时执行真实文件：Python 用 `py`/`python`，JavaScript 用 `node`，TypeScript 在 Node 22+ 直接运行、更早版本自动转译；
3. 输出显示在「CNShadow 运行」终端里，可以继续交互。

如果中文视图里存在未映射的标识符，运行会被取消并提示位置——避免执行一份和你在编辑器里看到的并不一致的代码。

## 中文映射表

按 `Ctrl+Alt+M` 打开，或者点状态栏的「中文映射表」。

- **搜索**：按英文路径或中文别名实时过滤。
- **分组**：全部 / 自定义 / 内置库三个视图，内置库按模块分组。
- **新增**：填写英文限定路径与中文别名，例如 `document.querySelector` → `文档.查询选择器`。
- **覆盖内置**：内置映射只读，点「自定义」即可用你自己的别名替换。
- 所有自定义别名写入工作区根目录的 `.cnmap`，建议提交到 Git，让团队共享同一套中文词汇。

```json
{
  "version": 1,
  "language": "mixed",
  "aliases": {
    "document.querySelector": "文档.查询选择器",
    "fetchUserData": "获取用户数据"
  }
}
```

中文别名规则：只允许中文、数字、下划线，可用点号分段；同一个别名不能指向两个不同的英文键。

## 中文模式的问题检测

中文关键字本身不是合法语法，所以 CNShadow 不走内置语言服务：

1. 先把中文内容反向还原成英文；
2. 对仍未映射的中文标识符做等长替换，避免再次产生假阳性；
3. TypeScript / JavaScript 用编译器 API 只做语法解析，Python 用解释器 `ast.parse`（不执行代码）；
4. 结果回填到中文文档的对应行。

因此：**中文关键字不会报错，真正的括号/冒号/缩进错误依然会被准确指出**。

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `cnshadow.enabled` | 开启 | 是否启用中英双语映射 |
| `cnshadow.maxFullParseLines` | `10000` | 超过行数只做关键字替换（降级模式） |
| `cnshadow.blockOnUnmappedAlias` | 开启 | 存在未映射中文标识符时阻止保存 |
| `cnshadow.diagnostics.enabled` | 开启 | 中文模式问题检测 |
| `cnshadow.completion.enabled` | 开启 | 中文模式库成员补全 |

## 常见问题

**保存时提示「发现未映射的中文标识符」？**
说明你写了自定义的中文变量名。切到英文视图，把光标放在对应的英文标识符上执行「CNShadow: 为标识符标注中文别名」，
或者直接在映射表里新增一条，然后保存即可。

**切到中文后看不到语法高亮？**
请确认文件是 `.ts` / `.js` / `.py` 之一；其它语言不支持映射切换。

**Python 补全没有内容？**
需要本机可用的 Python（`py` / `python` / `python3` 任一）。插件只用它读取模块信息和做语法检查，不会执行你的代码。

**卸载插件后代码会变中文吗？**
不会。磁盘上一直是英文，中文只存在于编辑器视图里。

## 隐私

- 所有转换都在本地完成，不上传任何代码。
- 只有 Python 模块内省与语法检查会启动本机解释器子进程，且只读取模块签名/执行 `ast.parse`。

```bash
npm run watch     # 开发时监听
```
